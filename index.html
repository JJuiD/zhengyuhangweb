Web UI 控件速查词典

设计 UI 时想用某个控件但叫不上名字？在这里用「口语描述」搜一下，就能看到它长什么样、专业术语叫什么。每个控件都可以直接上手玩。

🔍
支持搜索：中文名 / 英文名 / 口语叫法 / 用途关键词
😖 没找到匹配的控件，换个说法试试？
⌨️ 输入类

按钮

Button
💬 口语：能点的方块 / 确定、取消那种 / 点一下做事的东西
用在：提交表单、确认操作、触发动作。按重要程度选颜色，一个区域只放一个主要按钮。

文本输入框

Text Input
💬 口语：能打字的框 / 填东西的框 / 输入内容那条
用在：让用户输入单行文字，如搜索、账号、昵称。灰色不可用的叫「禁用状态」。

密码输入框

Password Input
💬 口语：打字变圆点 ●●● / 星号框 / 看不见字的框
用在：输入密码等不想被人看到的内容，输入内容自动打码显示。

多行文本框

Textarea
💬 口语：能打很多行字的大框 / 留言框 / 备注、简介那种
用在：留言、备注、简介等需要多行文字的地方，右下角可以拖拽调整大小。

下拉选择框

Select / Dropdown
💬 口语：点一下弹出一列选项的框 / 收起来的选项列表 / 选城市那种
用在：选项多而页面空间有限时，收起只占一行，点开后展开所有选项选一个。

日期 / 时间 / 颜色选择器

Date / Time / Color Picker
💬 口语：选日期弹日历的 / 选几点几分的 / 调颜色的色板
用在：选日期（点击弹出日历）、选时间、选颜色，避免用户手动输入格式错误。
✅ 选择类

复选框

Checkbox
💬 口语：打勾的小方框 ☑ / 能同时选好几个的 / 勾选框
用在：多选场景，如勾选多个文件、同意多个协议。方形，选中打勾。

单选按钮

Radio Button
💬 口语：小圆圈 ⦿ 只能选一个的 / 点一下中间变实心
用在：互斥选择，如性别、支付方式——多个选项里只能挑一个。圆形，选中变实心点。

开关

Switch / Toggle
💬 口语：拨来拨去的小滑块 / 电闸 / 一拨就开、再拨就关
用在：立即生效的开关场景，如「推送通知：开/关」。和单选不同——它只控制一个功能的启停。

滑块

Slider
💬 口语：一根杆拖着圆点左右拉 / 调音量那种 / 拖动条
用在：在一个连续范围内选值，如音量、透明度、价格区间。试试拖动 ↓

🔔 反馈类

提示条

Alert / Banner
💬 口语：一长条彩色通知 / 横幅提醒 / 页面顶部那条警告
用在：常驻在页面里的重要提示，如系统公告、表单错误汇总。颜色区分等级：蓝=信息、绿=成功、黄=警告、红=错误。
ℹ️ 信息提示（info）：这是一条普通信息。
✅ 成功提示（success）：操作已成功完成。
⚠️ 警告提示（warning）：请注意潜在的风险。
❌ 错误提示（error）：操作失败，请重试。

消息提示

Toast
💬 口语：屏幕下面弹一下就消失的小黑条 / 轻提示 / 气泡通知
用在：操作成功/失败的轻量反馈，几秒后自动消失，不打断用户。和模态框的区别：它不需要点关闭。

模态框

Modal / Dialog
💬 口语：弹出来的小窗 / 弹窗 / 背景变暗中间凸出一块
用在：需要用户必须处理的重要交互（确认删除、填写表单）。会挡住页面其他操作，所以不要滥用。

工具提示

Tooltip
💬 口语：鼠标放上去冒出来的小黑字 / 悬停说明 / 小气泡提示
用在：给图标、缩写等不易理解的东西补充说明。把鼠标移到下面文字上试试 ↓

进度条

Progress Bar
💬 口语：显示百分之多少的那根长条 / 一格一格涨的条
用在：上传、下载等耗时任务，告诉用户「进行到哪了」。
0%

加载中

Loading / Spinner
💬 口语：转圈圈 / 转菊花 🌀 / 一直在转的那个圈
用在：内容正在加载、请用户稍等的时候。
加载中…
🧭 导航类

标签页

Tabs
💬 口语：上面一排按钮、点一个换一块内容 / 页签 / 选项卡
用在：同一块区域切换多组内容，不用跳转页面。点下面试试 ↓
标签一 标签二 标签三

折叠面板

Accordion / Collapse
💬 口语：点标题展开、再点收起的 / 手风琴 / FAQ 那种一问一答
用在：内容多但不需要同时全看，如 FAQ、设置分组。点下面试试 ↓
什么是折叠面板？
就是你现在看到的这个——点标题展开内容，再点收起。前面的箭头会跟着转向。
它和标签页有什么区别？
标签页同一时刻只显示一块内容且互相排斥；折叠面板可以同时展开好几个。
常见使用场景？
常见问题解答（FAQ）、订单详情、高级设置选项。

面包屑

Breadcrumb
💬 口语：首页 > 分类 > 详情 那个路径条 / 显示你在哪一级的
用在：层级深的网站/后台，告诉用户「你在哪」，每一级都能点回去。
首页/ 电子产品/ 手机/ 某某型号

分页

Pagination
💬 口语：页码 1 2 3 下一页 / 翻页的那排数字
用在：列表数据太多一屏放不下，切成一页一页看。点下面试试 ↓
当前第 1 页

步骤条

Steps
💬 口语：第一步 → 第二步 → 第三步 那种 / 流程图一样的横条
用在：多步流程（注册、下单、向导），告诉用户流程有几步、走到哪了。点圆圈试试 ↓

📇 数据展示类

徽章 / 标签

Badge / Tag
💬 口语：小色块 / 贴纸 / 状态后面那个彩色小胶囊
用在：标记状态（进行中/已完成）或分类属性，圆角小胶囊样式。
进行中 已完成 待处理 已失败 已归档

表格

Table
💬 口语：Excel 那种横竖格子 / 一行一行的数据表
用在：展示结构化数据（多行多列）。第一行灰底的是表头。

头像

Avatar
💬 口语：圆圆的个人头像 / 用户小圆图 / 旁边那个人头
用在：表示用户/账号，导航栏、评论列表、成员列表里常见。没有照片时用姓名首字代替。
